Learning Journey学习旅程學習旅程

Frame, enrich, generate, revise.界定、补充、生成、修改。界定、補充、生成、修改。

The workflow stays explicit so students can see that good AI use is a sequence of choices, not a single magic prompt.流程被清楚展开，让学生看到好的 AI 使用是一连串选择，而不是一个神奇提示词。流程被清楚展開，讓學生看到好的 AI 使用是一連串選擇，而不是一個神奇提示詞。

01
Read the task before prompting写提示词前先读懂任务寫提示詞前先讀懂任務
Students identify the audience, success criteria, constraints, and unknowns before asking the model for help.学生先识别受众、成功标准、限制条件和未知点，再向模型求助。學生先識別受眾、成功標準、限制條件和未知點，再向模型求助。
02
Add context with a reason有理由地补充上下文有理由地補充上下文
References, examples, and files are added only when they clarify the task or reduce ambiguity.只有当参考资料、示例和文件能澄清任务或减少歧义时，才把它们加入。只有當參考資料、示例和文件能澄清任務或減少歧義時，才把它們加入。
03
Generate a first version生成第一个版本生成第一個版本
The first output is treated as material for review, comparison, and improvement rather than a final answer.第一个输出被当作评审、比较和改进的材料，而不是最终答案。第一個輸出被當作評審、比較和改進的材料，而不是最終答案。
04
Inspect, explain, and revise检查、解释并修改檢查、解釋並修改
Students compare the output against the task, name what is missing, and revise the prompt or context deliberately.学生把输出与任务对照，指出缺失内容，并有意识地修改提示词或上下文。學生把輸出與任務對照，指出缺失內容，並有意識地修改提示詞或上下文。
